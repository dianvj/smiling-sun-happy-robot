# Smiling Sun and Happy Robot

A deterministic Python program (standard library only) that draws a smiling
sun and a happy robot — `entry.png`.

Made for make.fun's `ai-happy-01` bounty ("Make the AI judge happy", $250).
Submitted 2026-11-14 as entry `01a1d9e1-66b6-726a-913f-82314f221635`.

## Run it

```sh
python3 main.py
```

`main.py` writes `entry.png` (1024×1024). Running it twice produces a
byte-identical file (sha256
`933b80bf95a5a3ea1936c253968d0f68b9d6557a2b7ada4880c4cf81655380d4`).
